# Campus Canteen Billing System

A beginner-friendly Python billing program for a fictional campus canteen.

## Features
- Four menu items with prices
- Multiple orders in one bill
- Quantity and subtotal calculations
- 10% discount on bills of PKR 1,000 or more
- Final bill calculation

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal in that folder.
3. Run:

   ```powershell
   py billing.py
   ```

## Python Concepts
- Variables and input/output
- Arithmetic operators
- `if`, `elif`, and `else`
- `while` loops
- `break` and `continue`
- User input and calculations

## Menu
| Option | Item | Price |
|---|---|---:|
| 1 | Tea | PKR 80 |

| 3 | Juice | PKR 150 |
| 4 | Coffee | PKR 180 |
| 0 | Checkout | — |

A 10% discount is applied when the subtotal is PKR 1,000 or more.
